# React Team Expense Tracker - Project Tasks

This document outlines the independent frontend development tasks for the React Team Expense Tracker.

---

## 📋 Task Breakdown

### Task 1: Core Layout & Form UI
- **Objective:** Create the main page layout, header, form input fields (description, amount, category), and responsive styling.
- **Components/Files:** `src/App.jsx`, `src/App.css`
- **Deliverables:** Form with description text input, amount numeric input, category selection dropdown, and submit button.

### Task 2: React State Management & Live Calculations
- **Objective:** Implement interactive React state using `useState` to store expenses and calculate the running total in real time.
- **Components/Files:** `src/App.jsx`
- **Deliverables:** Input validation, automatic total calculation, and dynamic expense list rendering.

### Task 3: Interactive Features (Delete & Category Filtering)
- **Objective:** Allow users to filter expenses by specific categories and remove unwanted expense records.
- **Components/Files:** `src/App.jsx`, `src/App.css`
- **Deliverables:** Category dropdown filter, category badges, individual delete buttons, and filtered total recalculation.
